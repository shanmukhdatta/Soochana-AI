# Frontend Components (`frontend/src/components/`)

This directory houses modular presentation components for the **Soochana AI** dashboard.

---

## 1. Component Inventory

* [`HomeLanding.tsx`](HomeLanding.tsx): Full-featured introduction and architecture portal:
  - Institutional value proposition and technical overview
  - Side-by-side comparison between **Quick View** (executive summaries) and **Analyst View** (probability distributions and quantitative audit)
  - Mathematical formulas summary (SLSQP constraints, Black-Scholes partial derivatives, 12-Month ECL accounting boundary)
  - Interactive deep-dive guide to testing live rebalancing and stress features
  - Developer attribution and source repository links
