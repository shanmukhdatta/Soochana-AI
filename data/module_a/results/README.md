# Module A Backtest Results (`data/module_a/results/`)

This directory stores outputs generated by the 357-session historical backtesting engine ([`scripts/run_module_a_backtest.py`](../../../scripts/run_module_a_backtest.py)).

---

## 1. Generated Reports

* `holdout_offline_comparison.json`: Comparative performance metrics across benchmark strategies:
  1. `equal_weight_buyhold`: Pure passive benchmark.
  2. `equal_weight_weekly`: Periodic calendar rebalance.
  3. `sentiment_only`: Tilting based exclusively on sentiment scores.
  4. `sentiment_impact`: Joint sentiment and XGBoost volatility severity weighting.
  5. `full_event_aware`: Complete multi-factor tactical strategy including event conviction.
