# Module B Stress Results (`data/module_b/results/`)

This directory stores outputs generated by stress testing and reverse stress demonstration scripts ([`scripts/run_module_b_demo.py`](../../../scripts/run_module_b_demo.py)).

---

## 1. Generated Reports

* `credit_stress_demo.json`: Position-level MTM revaluations and incremental 12-month ECL projections under credit deterioration.
* `reverse_stress_demo.json`: Parameter grid search identifying the first sampled shock threshold breaching the loss budget.
